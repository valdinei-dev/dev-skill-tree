# Data Model: Skill Detail Reading Accessibility

This feature does not add, remove, or change persisted entities.

Skill remains `id`, `name`, `description`, `priority`, `knowledge`, `notes`. Empty description and notes stay `""`. Priority and knowledge stay `1`–`5` in storage and human labels in the reading view.

No overlay state is added. Edit/Delete flags in Skill Detail stay as in `005` / `004`.
